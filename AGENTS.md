# Friemi UI development

For work on `apps/web` UI, read [docs/ui-design-system.md](docs/ui-design-system.md) and the existing page flow before editing. Preserve working actions, locale support, and the established brand tokens. Check the result in a browser at mobile and desktop widths.

Inventory items and mall gifts are different product flows. Keep their navigation and labels distinct.

# Git workflow

Run `git push` only when the user explicitly asks to push. Ordinary edits, tests, and local commits must not automatically trigger a push.
