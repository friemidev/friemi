# Friemi v2.7 页面人工测试计划

日期：2026-08-09

分支：`feature/v2-7-optimization`

本文用于人工验收 v2.7 涉及的页面改动。每个页面都列出建议测试方式和期望结果；验证通过后，再回到 `docs/v2_7/checklist.md` 勾选对应 checklist。

## 测试准备

### 设备和视口

- 桌面浏览器：Chrome 最新版，宽度 1280px 以上。
- 移动浏览器：Chrome mobile emulation `390x844`、`360x740`、`320x568`。
- 真机优先：iPhone Safari / WebKit、Android App WebView。
- 狼人杀多人：至少准备 8 / 10 / 12 人房间录屏，能模拟多账号或多设备更好。

### 账号和数据

- 账号 A：普通用户，已有头像、Profile 数据、Friemi 币余额。
- 账号 B：普通用户，与 A 未互关。
- 账号 C：与 A 互相关注。
- 活动 1：A 创建的公开聚吧，未开始。
- 活动 2：A 创建的公开聚吧，已经开始，无 `endAt`。
- 活动 3：已结束聚吧。
- 活动 4：公共活动 `PUBLIC_EVENT`。
- 活动 5：有群聊成员、公告、签到申请、协管。
- 礼物数据：至少包含一个可购买礼物、一个余额不足场景。
- 上传素材：`jpg`、`png`、`webp`、`gif`，每类各准备一张；另准备一个超过普通上限的非 GIF 图片和一个非图片文件。
