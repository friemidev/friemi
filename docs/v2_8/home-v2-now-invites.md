# Home V2 · 此刻邀约

首页的「此刻」展示一个人发起的一条短期邀约。其他人点泡泡进入详情，点「我也想」表示兴趣；举手不构成聚吧报名。

## 已实现的规则

- 发布者选择类型、标题、区域、选填说明与首页展示时长。可选 3、6、12、24 小时，默认 12 小时。倒计时从服务端创建时间开始，表示首页曝光剩余时间，与见面时间分开。
- 首页从目前已开放的巴黎邀约里展示最多六个未到期泡泡。大小由举手人数与发布时间决定；展示顺序加入小幅按访问变化的扰动，并优先覆盖不同类型。推荐逻辑集中在 `features/now/now.ts` 和 `features/now/queries.ts`，可由未来算法替换。
- 泡泡升起、轻微漂浮，点击时短暂破裂后进入详情。系统设置为减少动态效果时直接进入。倒计时在页面打开期间持续更新，到期的泡泡从首页退出。
- 到期后，发起者与仍在举手状态的人可从「我的此刻」进入详情、查看和留言。其他人不能通过到期邀约的直链查看交流内容。
- 发起者可选择已举手的人。被选中只表示组局邀请意向；对方仍需在聚吧页面正式报名。
- 发起者可从此刻详情进入现有聚吧创建表单，标题、说明、区域和类型会预填。创建成功后记录新聚吧的关联，并让原泡泡退出首页。

## 数据与审计

上线前需执行 `20261003120000_add_now_invites` 迁移。当前连接的预览数据库尚无新表，因此正式首页在迁移前呈现真实空状态。开发环境可打开 `/zh-CN/dev/now-preview` 查看标明为示例的泡泡布局与动效；该路由在非开发环境返回 404。

本阶段没有接入个性化推荐，也没有开放示意图中的付费放大泡泡功能。现有聚吧报名流程仍负责正式参加。
