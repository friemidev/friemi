## 2. 逻辑路由结构

```text
聚吧
└── event.detail                         聚吧详情页
    ├── event.chat                       聊天（既有能力）
    ├── event.announcements              公告（既有能力）
    ├── event.participants               参与者（既有能力）
    └── event.aa.center                  AA 核算中心
        ├── ?tab=transactions            明细页签（默认）
        ├── ?tab=settlement              结算页签
        ├── event.aa.transaction.new     记一笔：支出 / 收入 / 转账
        │   └── split-selector           选择分摊（页内步骤或底部弹层）
        ├── event.aa.transaction.detail  交易详情
        │   ├── edit                     编辑交易
        │   └── history                  修订历史（页内区块或弹层）
        ├── event.aa.reviews             费用与变更审核
        ├── event.aa.settlement.detail   单条付款路径 / 付款确认
        ├── event.aa.transfer.detail     转账确认 / 争议处理
        ├── event.aa.statistics          统计
        └── event.aa.settings            核算菜单与设置
            ├── members                  成员与权限
            ├── invitations              邀请与游客访问
            ├── payment-methods          收款方式授权
            ├── categories               分类管理
            ├── import                   CSV 导入
            ├── export                   导出
            ├── activity                 活动记录
            └── lifecycle                冻结 / 重开 / 归档 / 恢复 / 删除

外部入口
├── aa.invite                            邀请链接 / 二维码
├── aa.notification-target               通知深链目标
└── account.*                            账户升级、恢复、锁定与注销
```

路由约束：

- 不创建脱离聚吧的顶层 AA 首页或独立 `Settlement` 产品壳。
- “选择分摊”和“付款详情”优先作为任务页内步骤或底部弹层；如需支持通知深链，可以有可寻址状态，但不增加重复导航层级。
- 同一 `event_id` 只能进入同一个有效 AA 账本；重复点击或并发首次进入不得产生多个账本。
