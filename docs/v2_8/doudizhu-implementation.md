## 横屏规则

用户已明确手机斗地主与后续四川麻将使用横屏牌桌。叫分/对局/结果在手机竖屏时显示旋转提示；支持浏览器通过显式点击请求全屏和横屏锁定，不支持自动锁定的Safari/WebView需要用户横放手机。旋转不重置倒计时、不重发动作、不清空选牌；联机计时继续。本地三席预览计时暂停。原生壳的方向锁效果仍需设备验收。

## 本地启动

需要仓库指定的 Node 20.19.x / npm 10。工作树拥有独立依赖，不与其他任务共用生成的 Prisma Client。

```bash
npm ci
npm run db:generate --workspace=apps/web
npm run doudizhu:preview --workspace=apps/web
```

独立预览地址：`http://127.0.0.1:4186/`。可附加 `?locale=zh-CN&scene=entry`、`?locale=en&scene=lobby`、`?locale=fr&scene=table`。它使用真实引擎和实际组件，可切换三个座位手动操作；不会创建数据库房间，不是单人AI模式。

独立预览额外支持 `effect=straight|pairs|airplane|airplane-single|airplane-pair|rocket|bomb`，仅安排一副完整54张的固定测试牌序，方便真实叫3分后选出对应组合；不是自动播放或伪造PLAY事件。此参数只由本地独立预览入口读取，在线房间始终使用服务器洗牌。

完整应用用现有 Friemi 的本地认证/数据库环境运行 `npm run dev`。正常路由为 `/zh-CN/game-tools/doudizhu`（另有 `en`、`fr`）。不要将真实服务端数据放进预览夹具。

## 启用多人环境的顺序

1. 在目标测试环境备份并审核迁移。新增 `20261016120000_doudizhu_rooms` 与 `20261016123000_doudizhu_private_realtime`。先迁移后开放，勿在生产运行 `db push`。
2. 确认 Prisma 使用服务端数据库角色；浏览器只能走API。共享 Prisma 默认省略新字段，DDZ服务显式选取，避免功能关闭时破坏尚未迁移的其他游戏。
3. 配置现有 Clerk 与 Supabase Third-Party Auth，验证登录JWT的 `sub`/`authenticated` 角色可用于私有频道。普通Postgres没有Realtime schema时迁移跳过频道策略、快照轮询仍可工作。
4. 配置 `CRON_SECRET`，使用独立worker调用 `/api/cron/doudizhu-deadlines`。默认每2秒，不重叠请求；一次房间事务只推进一个行动。
5. 测试部署设置 `DOUDIZHU_ENABLED=true`。默认只有本机 `NODE_ENV=development` 开启；生产/托管预览默认关闭，`false`可明确关闭。
6. 完成三账号、三设备、全员离线到期、掉线恢复和声音检查后，再决定公开上线。

```bash
DDZ_DEADLINE_ENDPOINT=https://TEST_HOST/api/cron/doudizhu-deadlines \
  CRON_SECRET=YOUR_SECRET npm run doudizhu:deadlines --workspace=apps/web
```

不要将密钥写入命令历史、仓库或文档。部署时使用平台的安全环境变量注入，上述仅展示变量名称与关系。服务端广播只传版本通知；未连接私有频道时使用3秒快照兜底。

## 测试与证据

首版验证：游戏工具测试421项通过，实际PostgreSQL持久化检查114项通过，私有频道权限SQL断言17项通过。本轮牌型反馈更新后，游戏工具测试 **436项通过**（新增5项“不出”状态和10项牌型特效生命周期测试），TypeScript检查与完整Next.js生产构建通过。持久化和权限层本轮未变更；先前数据库证据不作为此次新增浏览器效果的证明。构建中的既有图片提示不影响通过。构建验证不代表生产部署。

浏览器已检查667×375与844×390横屏、1280×900桌面及390×844竖屏拦截。新版验证了17/20张整手可见、标准手机横屏无额外滚动，中英法主按钮/计时不被挤出；点选、横划并缩小选择区间、清空、网格展开/Escape焦点返回、End/Space键盘操作、转屏保留选择、完整一局及返厅。

已捕捉真实从大厅开始的发牌、领取底牌和出牌中间帧，确认51次发牌使用最多12个临时视觉牌对象且结束后清空。减少动态、竖屏拦截、恢复横屏不补播、主线程阻塞后丢弃过期动画也经过浏览器验证。截图保存在工作树的`output/playwright/doudizhu-v2-*.png`（开发产物，不纳入Git），先前无`v2`的牌桌截图为旧UI，不作为改版后的验收依据。

本轮按用户反馈去掉选中张数、选中牌型/点数、公开牌下重复姓名与牌型说明；必要错误改成三语短句并保留完整可访问说明。667×375中法语分别验证三席“不出”位置、双PASS同TRICK即时与800ms仍显示两标记、1600ms已清除、下一次PLAY立即清除。真实引擎出牌覆盖顺子、连对、裸飞机/带单/带对、炸弹、王炸七种输入；确认只选中不演出、接受后仅一次演出、结束不删除公开牌。手机效果边界在底牌信息行下方与操作行上方。还实打18手单牌后以双王收尾，验证PLAY与RESULT同快照时的紧凑提示及自动恢复结果标题，返回大厅按钮可见。本轮截图前缀为`output/playwright/doudizhu-effects-*`；竞品观察与原创设计区别见[牌型特效研究](doudizhu-combination-effects-study.md)。

牌型特效另经浏览器验证：减少动态时不演出但保留公开牌；开关减少动态与竖屏恢复后，冻结预览的第一手真实出牌仍触发；动画中转为竖屏在250ms内取消，恢复不补播；正常停顿7秒再出牌仍触发。覆盖667×375、844×390与1280×900；法语飞机带对标签也在安全区域内。当前自动化环境切换标签没有产生`document.hidden=true`，因此本轮后台恢复结论限于事件单元测试与监听器代码复审，不冒充真实后台浏览器验收。

规则测试覆盖发牌守恒、非法牌型、飞机附带限制、同牌型比较、牌权、末张炸弹、零和积分、截止边界、24局全员离线模拟、私有投影以及提示与穷举子集对照。
