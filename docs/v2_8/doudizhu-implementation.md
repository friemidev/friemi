## 横屏规则

用户已明确手机斗地主与后续四川麻将使用横屏牌桌。叫分/对局/结果在手机竖屏时显示旋转提示；支持浏览器通过显式点击请求全屏和横屏锁定，不支持自动锁定的Safari/WebView需要用户横放手机。旋转不重置倒计时、不重发动作、不清空选牌；联机计时继续。本地三席预览现在也默认真实计时、到期自动推进；仅显式加 `clock=frozen` 的截图夹具暂停。原生壳的方向锁效果仍需设备验收。

## 本地启动

需要仓库指定的 Node 20.19.x / npm 10。工作树拥有独立依赖，不与其他任务共用生成的 Prisma Client。

```bash
npm ci
npm run db:generate --workspace=apps/web
npm run doudizhu:preview --workspace=apps/web
```

独立预览地址：`http://127.0.0.1:4186/`。可附加 `?locale=zh-CN&scene=entry`、`?locale=en&scene=lobby`、`?locale=fr&scene=table`。它使用真实引擎和实际组件，可切换三个座位手动操作；默认计时会前进，到期调用同一引擎处理。不会创建数据库房间，不是策略AI模式。若要检查静态截图，可显式附加 `clock=frozen`。

独立预览额外支持 `effect=straight|pairs|airplane|airplane-single|airplane-pair|rocket|bomb`，仅安排一副完整54张的固定测试牌序，方便真实叫3分后选出对应组合；不是自动播放或伪造PLAY事件。此参数只由本地独立预览入口读取，在线房间始终使用服务器洗牌。

完整应用用现有 Friemi 的本地认证/数据库环境运行 `npm run dev`。正常路由为 `/zh-CN/game-tools/doudizhu`（另有 `en`、`fr`）。不要将真实服务端数据放进预览夹具。

## 启用多人环境的顺序

1. 在目标测试环境备份并审核迁移。新增 `20261016120000_doudizhu_rooms` 与 `20261016123000_doudizhu_private_realtime`。先迁移后开放，勿在生产运行 `db push`。
2. 确认 Prisma 使用服务端数据库角色；浏览器只能走API。共享 Prisma 默认省略新字段，DDZ服务显式选取，避免功能关闭时破坏尚未迁移的其他游戏。
3. 配置现有 Clerk 与 Supabase Third-Party Auth，验证登录JWT的 `sub`/`authenticated` 角色可用于私有频道。普通Postgres没有Realtime schema时迁移跳过频道策略、快照轮询仍可工作。
4. 配置 `CRON_SECRET`，使用独立worker调用 `/api/cron/doudizhu-deadlines`。默认每2秒，不重叠请求；一次房间事务只推进一个行动。
5. 测试部署设置 `DOUDIZHU_ENABLED=true`。默认只有本机 `NODE_ENV=development` 开启；生产/托管预览默认关闭，`false`可明确关闭。
6. 完成三账号、三设备、全员离线到期、掉线恢复和声音检查后，再决定公开上线。

```bash
DDZ_DEADLINE_ENDPOINT=https://TEST_HOST/api/cron/doudizhu-deadlines \
  CRON_SECRET=YOUR_SECRET npm run doudizhu:deadlines --workspace=apps/web
```

不要将密钥写入命令历史、仓库或文档。部署时使用平台的安全环境变量注入，上述仅展示变量名称与关系。服务端广播只传版本通知；未连接私有频道时使用3秒快照兜底。

## 叫分与倒计时调整（2026-10-16）

叫分按钮明确显示“1分、2分、3分”，英文/法文保留对应 point/points 单位；最高叫分与座位叫分状态同步。新局人工出牌默认60秒，采用现有 UNO 的默认值（`unoEngine.ts`）；画猜绘画默认60秒但属于不同阶段，不直接复制其超时动作。叫分20秒、后续托管4秒保持。旧进行中30秒局不改当前截止时间，下一局采用60秒。

跟牌超时一律“不出”，取消先前“可以一次出完就自动出牌”的例外；领出回合不允许PASS，超时出最小单张以保证继续。首次超时进入托管，可用“接管”恢复人工操作且不重置本回合期限。正常预览不再冻结时钟，真实走时并自动处理叫分、出牌及结果到期；转竖屏计时也继续。

本轮游戏工具452项测试通过，含21项引擎测试与24个种子的全员超时整局回归，类型检查及完整Next.js生产构建通过。浏览器真实走时从60降为59后，使用Playwright受控时钟推进到期，验证首出最小单张、跟牌自动不出且手牌不减少、双PASS交还牌权、4秒托管、20秒叫分超时和显式冻结夹具。另从大厅三人准备开始，58次自动超时完成一局，并验证结果到期返厅重置全部准备状态。中英法×667×375/1280×800共6组叫分单位和倒计时布局验证无溢出、无控制台错误；844×390验证最后5秒强调。证据为 `output/playwright/doudizhu-countdown-*` 和 `doudizhu-bid-units-*`，设备真机和多人线上条件仍按上文独立验收。

## 房间设置与多局记分（2026-10-16）
