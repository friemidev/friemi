# 斗地主房间设置、多局计分与整场结算

日期：2026-10-16。分支：`二游`。本轮按用户要求补齐房间设置、记分板、可选局数与当前轮次。

## 房间规则

- 默认6局一场，房主可选择1、3、6、12局。这是本项目的默认安排，不宣称为斗地主统一比赛规则。
- 出牌时限可选30、60、90秒，默认60秒沿用当前UNO默认值；叫分20秒、托管4秒保持。
- 每副牌打完算一局；全不叫后的重新发牌仍属于同一局，不额外增加进度。
- 房主在开场前和整场结束后可修改设置，其他玩家可查看。本场已经开始后，局间也不允许修改设置。
- 设置真正改变时，全员重新准备；重复请求和无变化的保存不反复清空准备。换猫不会改变计分或准备状态。

## 对局与结算

牌桌显示“第N/M局”。每局结束保留本局胜负、叫分、倍数与分数增减，同时累加到整场积分。局间返回大厅，三人重新准备，由房主开始下一局；不会在有人尚未确认时直接发下一副牌。

达到指定局数后，结果页突出整场累计排名。相同积分并列，最终排名不以座位顺序打破平局。返回大厅后可以再开一场，旧场分数归零；房间的历史局号继续递增，用于拒绝旧命令和避免重复结算。

记分板在大厅、牌桌和结算均可打开，展示当前进度、各人的累计积分、胜局数、最近一局增减和逐局明细。三人完整积分总和始终为0；每一局仅能计分一次，刷新、重连、请求重试或重复到期扫描不应再加分。

## 成员与隐私

累计分数绑定整场的固定三人阵容。掉线恢复、原账户回到原座位不会重置；大厅发生参与账号或座位阵容变化，则结束旧阵容的累计并为新阵容重新计分，保留房间设置。新加入者不能继承上一位玩家的分数，也不能通过当前记分板看到旧阵容数据。

内部可使用账号ID核验阵容；公开状态和记分板不得带出账号ID、身份键或未公开手牌。以往单局记录仍按原参与账号授权，离席者不因失去座位而失去自己的历史记录。

## 实施与验证

规则与积分保存在原房间JSON状态中，共用纯引擎与服务端房间锁，不另建与真实状态脱节的UI积分。服务端设置接口使用既有身份验证、房主权限、版本检查、命令回执及未知结果重试机制。原有房间状态缺少新增字段时使用兼容默认值，不把已有历史局数误当成本场进度。

本地预览使用同一设置和累计逻辑。手机横屏优先保留牌、操作与倒计时；逐局明细放入可滚动记分板弹窗，桌面与手机保持一致含义。中英法文案同步。
