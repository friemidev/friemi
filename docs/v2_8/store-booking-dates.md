# 长期聚吧与门店预约

## 2026-10-09 确认的产品模型

Friemi 继续以聚吧和组局为核心。拥有门店的账号可直接创建一次长期聚吧，并设置开放日期；用户从长期聚吧预约具体日期与人数，门店逐笔接受或拒绝，无需管理员额外授权。长期聚吧出现在现有聚吧发现流中，不新增首页门店目录。

- 开放规则支持每天、每周多选和指定日期，也支持开始日期、可选结束日期及不开放日期。
- 本期只选日期，无时段、支付或短信。联系电话必填；联系人可沿用昵称，备注可选。
- 公开内容包括长期聚吧介绍、门店地址、开放日期、各日期已接受的预约人数。电话、联系人、备注、拒绝原因和个人记录只提供给预约本人或现任店主。
- 每个门店最多一个长期聚吧。修改规则复用原聚吧和链接；已有预约保持原日期、人数与状态，不能因调整规则自动取消。
- 门店自行开启、暂停或恢复预约；暂停预约、停用门店或店主停用会阻止新预约。已有预约仍可查看和处理。普通账号没有门店管理入口，也不能操作商家的预约设置和记录。
- 票券赠送与核销、优惠券是已有独立业务；预约不会新增物品、自动扣票或创建普通聚吧参与者。

## 页面层级

| 身份       | 入口                       | 下一级                   | 主要操作                                     |
| ---------- | -------------------------- | ------------------------ | -------------------------------------------- |
| 网站管理员 | 门店后台 → 门店预约        | 门店预约概况             | 查看预约状态与长期聚吧                       |
| 商家       | 我的 → 门店管理 → 门店预约 | 开放设置                 | 创建长期聚吧、上传封面、设置周期、暂停或恢复 |
| 商家       | 门店预约 → 预约记录        | 单笔预约详情             | 看日期、人数、电话；联系客户；接受或拒绝     |
| 公众       | 聚吧 → 长期聚吧            | 选择日期、人数、联系方式 | 登录后提交预约                               |
| 预约用户   | 我的 → 我的预约            | 单笔预约详情             | 看处理结果和拒绝原因；取消有效预约           |

路由：

- `/admin/merchants/bookings`：门店预约概况列表，支持搜索和分页。
- `/admin/merchants/[merchantId]/bookings`：单店预约状态和长期聚吧入口。
- `/profile/store/bookings`：商家预约记录。
- `/profile/store/bookings/settings`：开放设置。
- `/profile/store/bookings/reservations/[bookingId]`：商家单笔预约。
- `/lobby/[activityId]`：长期聚吧和公开预约日历。
- `/profile/bookings`、`/profile/bookings/[bookingId]`：用户本人预约。

## 状态与通知

1. 用户提交后进入 `PENDING`，商家收到站内通知。
2. 商家接受后变为 `ACCEPTED`；拒绝并填写原因后变为 `REJECTED`。用户收到处理结果通知。
3. 用户可取消未过期的待确认或已接受预约，状态变为 `CANCELLED`，商家收到通知。
4. 已接受、拒绝和取消记录保留。一个账号在同店同日期最多一笔有效预约；重复提交返回原预约，拒绝或取消后可重新提交。
5. 电话可从商家预约详情直接拨打。通知及移动推送只含门店、日期和人数，不含联系方式或私人备注；通知打开对应身份的预约详情。

公开人数只汇总 `ACCEPTED.partySize`，不把待确认账号数当作预约人数。操作在服务端检查当前身份和状态，事务及部分唯一索引处理重复提交和并发状态变更。

## 长期聚吧接入

长期聚吧用 `Activity.isPersistent` 和 `source=MERCHANT_BOOKING` 标识，不按普通活动开始时间判断结束或归档。卡片展示长期聚吧与预约入口，不显示虚假的单次开始时间、容量或参与人数。

长期卡片按最近预约时间排序，与原聚吧流统一分页；普通活动的相对顺序保持一致。当前实现读取匹配结果的轻量排序索引，再获取当页详情。数据规模增大时需重新评估这一查询的开销。

普通聚吧的报名、退出、复制、取消、编辑、奖励及聊天室自动加入不适用于长期聚吧；预约由独立预约记录管理。
