# Friemi 骰子游戏 · 可玩样机

画风参考当前「你画我猜」：雾蓝、奶白、蓝墨与原有猫咪。骰子使用明亮抛光树脂三维模型渲染的透明Sprite，共236帧，六种结果固定面映射。

样机支持自由摇骰与「你 + 3位电脑」的吹牛练习。2026-10-11第七次修订补充修复动态偏好切换、盖盅期间旋转屏幕及窄屏大字号布局；主桌继续保留精简文案。

- `index.html`：自由摇骰与本机四人吹牛练习入口。
- `sprite-lab.html`：六个落点、循环旋转、停稳轻摆、暂停、重播、逐帧、变速及六骰错峰。
- `assets/dice-3d/README.md`：图集规格、单帧PNG、manifest和重生成方法。
- `../dice-game-design.md`：完整规则、新手提示、正式房间、异常恢复、系统约定与实施验收。
- `assets/cats/players/README.md`：角色资产来源、状态和重生成方法。
- `assets/art-direction/README.md`：早期内置imagegen材质参考的生成提示词；该图不用于游戏动画，当前v2光泽版以实际三维渲染为准。

本目录无需构建或安装依赖。从上级目录启动静态服务：

```bash
python3 -m http.server 4177 --bind 127.0.0.1
```

打开 `http://127.0.0.1:4177/dice-design-preview/`。声音默认关闭。自由摇骰可选1–6颗，本轮增加1–2颗放大、收拢盖盅与可选快摇。

## 本机吹牛练习

这是1位玩家与3位电脑共用本机运行的练习桌，不连接真人房间。每人5颗，共20颗；1是百搭，可当作2–6点，因此叫点只能选2–6。首叫至少4个；数量相同要加大点面，数量增加可以换点面。猜的是全桌**至少**有多少个目标点，实际数量达到叫数时叫点者赢，否则挑战者赢。

已实现自主选择数量和点面、合法范围提示、最近叫点、角色发言与行动轮次、自己的骰子盖住／查看、逐组开盅及「直接看结果」、结算说明和新随机牌局。电脑依据自己的骰子与公开叫点决策；查看规则或记录时暂停，关闭后继续。手牌统计明确对应桌上当前叫点。练习无需登录；客户端的隐藏显示不构成服务端保密或防作弊。

桃桃使用面包喵，小鹿使用学者喵，猫猫使用船长喵，我使用云朵喵。四个角色直接从现有你画我猜组件导出，表情只跟随公开动作与结果。发言角色与气泡明确对应；开盅后各骰组保留原角色，胜负分别表现开心与失落，新局清除旧反馈。正式大厅的15角色选择、偏好保存、邀请、联网同步、断线恢复与3／5／7局赛制继续作为正式实施设计。

## 第二轮边界检查

- 小屏双击「再来一局」的第二击会落到新局叫点按钮。新局对提交动作设置400ms保护，忽略连击，并把键盘焦点移到数量输入；长按Enter不再误提交。
- 自由模式改骰数时重建按钮导致键盘焦点丢失。现在选中后焦点留在该数量，Tab继续前进。

- 盖住手牌会让叫点按钮上跳、切换按钮横移。手牌统计区域和按钮宽度保持稳定。
