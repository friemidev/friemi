# 你画我猜 P1 实施与验收记录

更新于 2026-09-28。P1 的存储、举报、异常提示和运维接口已在本地实现并通过隔离数据库验证；Preview 环境和真实多设备验收尚未完成，因此不能标记 P1 闭环，也不能开放接龙灰度。

## 本次实现

1. **作品与命令持久化**：接龙作品和草稿存入 `DrawGuessArtwork`，以房间、局号、链作者座位和棒次唯一标识；笔画 JSON 与服务器生成的 PNG 同存于私有 PostgreSQL 表。PNG 上限 512 KB，仅已结束局的房间成员可通过鉴权 API 读取。命令去重结果存入 `DrawGuessCommand`，房间快照中的作品笔画、草稿和命令结果清空；读取本人房间快照与往期作品时从记录恢复。旧格式房间在下一次写入时迁移原有作品与命令结果。
2. **内容与举报**：手动词限制为可见文字，拒绝链接、长数字、控制字符与内置阻断词片段；房间揭晓后可举报词或画。举报按成员、作品和局号唯一，单用户每小时最多 10 条；审核人员可通过管理员 API 查询并标记“已审/驳回”，结果不影响既有投票或分数。
3. **通知与失败提示**：房间订阅成功后重新获取本人服务端快照；Broadcast 不可用时继续 2 秒轮询，并明确说明画笔不会实时传输。补登录失效、人数不足、阶段结束、暂停新局、草稿保存失败和超时推进提示。
4. **运维边界**：接龙新局默认关闭，`DRAW_GUESS_CHAIN_ENABLED=true` 才允许新房间、开局与再来一局，已在进行的局仍可完成。管理员健康接口提供活跃/逾期房间数、待审举报数和 Realtime 环境变量就绪状态。阶段推进、重复命令、预览生成与持久化失败写结构化日志；截止扫描有错误或积压时报警日志。部署后每日运行维护任务：命令结果保留 30 天，已归档局的未提交草稿保留 7 天，即使同一房间已开始下一局也会清理；已结束房间和作品最多保留 365 天，未处理举报阻止房间清理。

## 本地证据

- 隔离 PostgreSQL 17 上 72 个迁移全部成功，未修改远端或生产数据库。
- P0 的 5、6、7、8 人完整接龙、并发与唯一结算回归通过。
- P1 集成脚本验证：房间快照无笔画/命令累积、草稿恢复、PNG 签名与大小、未揭晓拒读、成员授权读取、旧局作品恢复、旧格式房间再来一局时的作品迁移、举报去重/权限/并发配额、审核、暂停开局、保留期清理与未结举报保护。
- 本地 Next 页面验证：维护任务无凭证返回 401、携带本地密钥返回 200；手机 390 px 和桌面 1280 px 的房间及历史页无横向溢出、图片无破损、举报表单成功提交，控制台无错误或警告。截图保存在本地 `output/playwright/draw-guess-p1-*.png`。
- 复核时补充：房间轮询以修订号返回 304，只有变化或截止时间到期才从作品表恢复笔画；恢复查询不会读取 PNG 二进制。隔离数据库验证已归档局草稿的 7 天清理与当前局草稿保留。本机现有 Supabase 测试配置可订阅随机临时频道，服务端广播返回 202 且订阅者确实收到事件；此结果不是 Preview 真实房间验收。
- 画猜分支已生成独立 Ready Preview；对比 Vercel Preview 与 Production 的数据库项目标识后，向隔离的 Preview 库应用 3 个画猜迁移，状态为 72 个迁移全部最新。仅对画猜分支的 Preview 设置 `DRAW_GUESS_CHAIN_ENABLED=true`，新部署已生效。Preview Supabase Cron 的 5 秒任务连续成功，Vault 鉴权请求收到 200；5 人临时房间在全员离线时自动跨阶段，Preview 服务的 Supabase Broadcast 到达订阅者，测试数据已清除。

## 部署前仍需完成

1. P0 尚缺 Preview 中真实 Clerk 身份、5–8 台设备完整对局与独立截止扫描进程验收；P1 的发布状态不能越过 P0。
   用户打开的 Frieme.Dev Chrome 会话可读取 Vercel 项目；CLI 登录另一账号。画猜分支已有独立 Preview，数据库迁移和独立 5 秒扫描已完成，但没有共享的真实 Clerk 测试账号；仍需 5–8 个独立会话完成 UI 对局、断线与回放验收。
2. Preview 的 Supabase 公开密钥和服务端 Broadcast 已通过临时订阅者与自动推进事件验证；`CRON_SECRET` 的服务器鉴权也返回 200。仍需用真实 Clerk 设备验证房间内订阅、断线恢复与轮询降级，并通过管理员接口 `/api/admin/draw-guess/health` 复核配置和逾期房间指标。不要在文档记录任何密钥值。
3. 接入现有监控系统的告警接收方：到期扫描返回错误、`overdueRooms > 0` 持续出现、预览/持久化错误日志、待审举报积压都需要实际通知并演练。当前只有可供监控采集的接口、状态码和日志，尚无外部告警接收配置。
4. 在 Preview 复查跨设备草稿、旧局 PNG 的授权读写、举报审核权限、365 天清理任务与回滚开关；用真实画作评估数据库体积和读取延迟，再决定灰度规模。PNG 存放于私有数据库表，较外部对象存储简化了成员鉴权，但会增加数据库容量，需要测量实际成本。

P1 达标后才可把接龙模式小范围灰度；普通抢猜的画笔实时性仍按 P2、P3 验收。
