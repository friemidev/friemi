## 可以做什么

### 找活动

浏览展览、音乐、运动、美食等活动，查看时间和地点，收藏想去的地方。看到感兴趣的活动，也可以围绕它发起聚吧，找人同行。

### 约一场聚吧

时间、地点、人数、费用和报名都在同一个聚吧里。发起人管理报名，大家在群聊里商量安排，用投票做决定，通过链接或二维码邀请朋友。

一起花的钱可以记在**记账本**里，核对谁付了钱、怎么分摊、各自应付或应收多少，再跟进结算。实际转账由参与者自行完成。

### 经营一个星球

星球是围绕共同兴趣的社群。成员可以聊天、分享图文和视频、继续组织聚吧；主理人可以管理成员和加入申请。

### 分享日常，保持联系

在世界页发布图文，关注感兴趣的人，和互关的朋友私聊。个人空间里可以查看自己的聚吧、收藏和成就，朋友送来的礼物会留在礼物墙上。

### 预约门店，管理券和票

门店通过长期聚吧接受预约。选择日期和人数后，就能在预约记录里跟进店主的回复。背包用于查看持有的优惠券和票券，商城则用来给朋友送礼物。
