# Draw & Guess audio sources

All source pages list **CC0**. Attribution is included here as a courtesy. The game serves edited, volume-balanced versions of these recordings. Run `python3 apps/web/scripts/generate-draw-guess-sounds.py` from the repository root to rebuild the files; `ffmpeg` and network access are required.

| Game audio | Creator and source | Source file |
| --- | --- | --- |
| `cat.wav`, `purr.wav` | Kerzoven, [Cat Purr & Meow](https://opengameart.org/content/cat-purr-meow) | `cat_mewfood.wav`, `cat_mewpurr.wav` |
| `tap.wav`, `ready.wav`, `next.wav` and accents in other cues | EZduzziteh, [Pop sounds](https://opengameart.org/content/pop-sounds-0) | `pop2.wav`, `pop3.wav`, `pop5.wav`, `pop6.wav`, `pop8.wav`, `pop9.wav` |
| `secret.wav`, `start.wav`, `wrong.wav` | bart, [Squeak toy sounds](https://opengameart.org/content/squeak-toy-sounds) | `squeak_toy.zip` |
| `correct.wav` | Fupi, [Correct Bell](https://opengameart.org/content/correct-bell) | `bell.wav` |
| `score.wav` | Spring Spring / Julie Damsgaard, [Pleasing Bell Sound Effect](https://opengameart.org/content/pleasing-bell-sound-effect) | `pleasing-bell.wav` |
| `finish.wav` | Fupi, [Win Jingle](https://opengameart.org/content/win-jingle) | `winfretless_0.ogg` |
| `music-lobby.mp3` (2:08) | MintoDog, [Cozy Puzzle In-Game 2](https://opengameart.org/content/cozy-puzzle-in-game-2) | `cozy_puzzle_in-game_2_bpm90.mp3` |
| `music-game.mp3` (2:10) | MintoDog, [Cozy Puzzle In-Game 1](https://opengameart.org/content/cozy-puzzle-in-game-1) | `cozy_puzzle_in-game_1_bpm118.mp3` |

`demo.wav` joins the eleven game cues with short pauses. Sound effects and music are on by default and can be muted separately. Browsers may wait for the first player interaction before starting music. The music changes from the relaxed lobby track to the more energetic game track when a round starts.
